## A warning about that gate, learned the hard way today

**The first clip of this session PASSED the ghost gate at 0.00095 and was unusable.**
`scene()` dropped the robot reference at the origin, so its legs were under the ground
plane: 240 frames of a torso and head sliding across a grid with nothing below the
pelvis. The gate measures temporal trails. It has no opinion about whether the subject is
intact, framed, lit, or even present.

Fixed (`FILM_SPAWN_Z`, default 0.80, from the same source the twin spawns at) and
re-shot; `frames/*_f120.png` are in this directory so the next person can check in one
look rather than trusting the number.

**MM8's acceptance criterion — "ghosting test green on every clip" — is necessary and
not sufficient.** Every clip needs a rendered frame looked at before it counts.
